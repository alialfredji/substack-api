# Privacy policy for the Substack API plugin

The Substack API plugin provides read-only access to information that Substack exposes publicly. The hosted MCP service does not require an account, accept Substack session cookies, or intentionally collect personal information from users.

Requests may be recorded temporarily in standard infrastructure logs for security, reliability, and debugging. Do not send secrets, session cookies, private data, or sensitive personal information in tool arguments. The service does not sell user data.

Substack is a third-party service. Data returned by the plugin is subject to Substack's availability and policies. Questions or deletion requests can be submitted through the repository's public issue tracker.
