substack-api

A typed TypeScript client and a documented REST gateway over Substack's public, undocumented API. Read-only. Cookie optional.

Quickstart

git clone https://github.com/alialfredji/substack-api.git
cd substack-api
npm install
npm run dev   # Swagger UI at http://127.0.0.1:3000/docs

What it's for

Finding people and publications — profile search, subscription graphs, note engagement, category leaderboards — so a tool can rank who is worth engaging with.

Substack will not tell you who subscribes to a publication. It will tell you, for any person, what they subscribe to. So you invert the query: gather candidates from public engagement surfaces, then score each by subscription overlap with your own reading.

Surfaces

profiles
Lookup by handle or id, people search, subscription lists, overlap scoring.
notes
Reactors with viewer-relative flags, per-profile and suggested feeds.
publications
Search, archives, posts, comment threads, deduped commenters, recommendation graph.
discovery
Category taxonomy and leaderboards.

Read-only, on purpose

Reads are anonymous and IP-scoped. Writes would mean sending your session cookie at machine speed to paths Substack's own robots.txt disallows. So: automate the targeting, perform the engagement yourself. Full reasoning in UPSTREAM.md.

About this page

This is documentation only — there is no hosted API. The gateway runs on your own machine, so the reference targets http://127.0.0.1:3000. Start it with npm run dev and "Test Request" will work against your local server.
